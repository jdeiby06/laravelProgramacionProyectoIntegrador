# laravelProgramacion3
# Como iniciar el proyecto:

## 1. Setup principal
- Clonar la rama cambios-dashboard.
- Iniciar APACHE y MSQL (Puerto 3306) en XAMPP.

## 2. Lanzar e ingresar al dashboard
- Ejecutar el comando cd holalaravel-main, despues php artisan serve en la consola de comandos cmd o git bash de VSC.
- Ingresar a la url proporcionada por el comando php artisan serve.
- Clic a Login en la parte superior derecha.
- Ingresar el correo y contraseña del usuario a seleccionar.
#### Admin: admin@gmail.com
#### User: user@gmail.com
#### Password: 12345678

## 3. Crear Productos y categorias
- Ingresar con el rol Admin.
- Seleccionar Categorias/Productos en el dashboard.
- Clic al boton "Crear Producto/Categoria".
- Rellenar el formulario con la informacion solicitada (incluyendo una imagen para el Producto).
- Al guardar, el cambio se vera reflejado en el sistema.

## 4. Registrar ventas
- Iniciar como User.
- Ingresar a "Productos" y darle clic al boton "Registrar venta".
- Seleccionar la cantidad del producto vendido y guardar el registro de la venta.

 ## 5. Editar Productos y categorias
 - Ingresar con el rol Admin.
 - Seleccionar Categorias/Productos en el dashboard.
 - Darle clic al icono de lapiz.
 - Realizar los cambios y guardarlos.

## 6. Eliminar Productos y Categorias
 - Ingresar con el rol Admin.
 - Seleccionar Categorias/Productos en el dashboard.
 - Darle clic al icono de contenedor de basura.
 - Confirmar la accion.
 - El sistema borrara el producto y/o categoria junto a los registros asociados a esta.
